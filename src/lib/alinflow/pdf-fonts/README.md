# PDF font

`DejaVuSans.ttf` is bundled unchanged with the application for server-side PDF generation, including Hungarian ő/ű glyphs. It is embedded as a subset in the resulting PDFs, without an external font service.

Upstream: https://dejavu-fonts.github.io/ and https://github.com/dejavu-fonts/dejavu-fonts

The accompanying `LICENSE.txt` contains the upstream redistribution notices. The font was copied from the bundled Poppler runtime distribution; no system-installed commercial font is required.
